# Install Nakkad on your phone — 100% free, no app store needed

## Android (2 ways)

### Option A — Install as app (recommended, 30 seconds)
1. Open **Chrome** on your phone
2. Go to **https://iamwinter1116-void.github.io/nakkad/**
3. Tap **⋮** (three dots) → **Add to Home screen** → **Install**
4. Nakkad now appears in your app drawer like any native app — full screen, its own icon, works offline.

### Option B — Sideload the APK (true offline, nothing downloaded at runtime)
1. On your phone: **Settings → Security → Install unknown apps** — allow for Chrome/Files
2. Download the APK: repo → **Actions** → latest **"Android APK"** run → **nakkad-debug-apk** artifact
3. Tap the downloaded file → **Install** (accept the "unknown sources" prompt)
4. The entire app is bundled inside — zero data usage after install.

## iPhone / iPad (30 seconds, no App Store, no developer account)

1. Open **Safari** (must be Safari, not Chrome — iOS only allows Safari to install web apps)
2. Go to **https://iamwinter1116-void.github.io/nakkad/**
3. Tap the **Share** button (square with arrow) → scroll down → **Add to Home Screen**
4. Tap **Add**. Nakkad appears on your home screen with its own icon, opens full-screen (no Safari bars), works offline.

**Why no App Store?** Apple charges $99/year for a developer account and requires a Mac + review process. The Add-to-Home-Screen path gives you the identical app at ₹0 — full offline, standalone display, own icon. When Nakkad earns money, we can revisit the App Store.

## Desktop (bonus)

Any Chromium browser (Chrome/Edge/Brave) → address bar → **install icon** (screen with arrow) → Install. Same offline capability.
